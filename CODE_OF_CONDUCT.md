# Code of Conduct

## Our standards

Contributors must communicate respectfully, welcome constructive feedback, and avoid harassment, discrimination, personal attacks, or publishing another person's private information.

## Scope

This policy applies in repository issues, pull requests, discussions, reviews, and other project spaces.

## Enforcement

Report unacceptable behavior privately to the maintainer through the GitHub account `ber-ners`. The maintainer may edit or remove contributions and temporarily or permanently restrict participation when necessary.
