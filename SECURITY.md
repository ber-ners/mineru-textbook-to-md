# Security Policy

## Supported versions

Security fixes are provided for the latest release on the default branch.

## Reporting a vulnerability

Do not open a public issue for a security vulnerability. Use GitHub private vulnerability reporting for this repository, or contact the maintainer through the GitHub account `ber-ners`.

Include a minimal synthetic reproduction. Do not attach API tokens, PDFs, extracted document content, personal data, or real local paths.

Reports involving ZIP extraction, path traversal, credential exposure, unintended uploads, unsafe overwrite behavior, or proxy bypass are especially important.
